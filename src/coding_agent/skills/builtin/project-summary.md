For project explanation tasks:

1. Use project memory only as orientation; inspect the current workspace before explaining.
2. Describe what the project does, the important files, how to run it, and how it is tested.
3. Mention recent user decisions or task history only when it helps answer the user's request.
4. Do not invent missing architecture. Say what is not clear from the files.
