For web UI work:

1. Make the primary workflow usable as the first screen, not hidden behind explanatory text.
2. Show user actions immediately, then reconcile with backend state.
3. Surface task progress, errors, and completion states in the UI.
4. Keep controls responsive across narrow and wide viewports.
5. Test at least one request path, state transition, or rendering contract affected by the change.
